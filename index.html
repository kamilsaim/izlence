TMDB API anahtarı

themoviedb.org → Settings → API bölümünden ücretsiz alınır. Anahtar yalnızca bu cihazda (localStorage) saklanır, hiçbir sunucuya gönderilmez.

TMDB anahtarı nasıl alınır? (formu hazır doldurduk)
  1. themoviedb.org üzerinden ücretsiz hesap aç ve e-postanı doğrula.
  2. Ayarlar → API → Create sayfasında Developer seçeneğini seç, sözleşmeyi kabul et.
  3. Açılan formu aşağıdaki değerlerle doldur — her satırı tek dokunuşla kopyalayabilirsin.
  4. Kaydettikten sonra API Key (v3 auth) değerini kopyalayıp yukarıdaki kutuya yapıştır.

Application Summary — İngilizce istiyor, en az 4 cümle
Izlence is a personal movie diary and recommendation web app. Users mark films they have watched, rate them and keep private notes. The app analyses this history by genre, director and decade, then suggests new films to watch. The TMDB API is used only to search titles and display posters, overviews and credits. It is a free, non-commercial hobby project with no advertising, and all user data stays in the browser's local storage.

Türkçe karşılığı: İzlence, kişisel bir film günlüğü ve öneri uygulamasıdır. Kullanıcı izlediği filmleri işaretler, puanlar ve not alır; uygulama bu geçmişe bakarak tür, yönetmen ve dönem analizleri üretir ve yeni film önerir. TMDB API'si yalnızca film arama, afiş, özet ve kredi bilgilerini göstermek için kullanılır. Ticari kullanım yoktur, reklam gösterilmez ve veriler kullanıcının kendi tarayıcısında saklanır.

Adres/telefon alanları zorunlu görünür; kendi bilgilerini yaz. TMDB bu bilgileri yayınlamaz. Onay genelde anındadır.

Google AI (Gemini) anahtarı — isteğe bağlı

aistudio.google.com → Get API key. Ücretsiz katman kişisel kullanım için yeterlidir. Anahtar yalnızca bu cihazda saklanır; olmazsa uygulama klasik öneri motoruyla çalışmaya devam eder.

Dil ve bölge

İzleme platformlarım

Seçtiğin platformları işaretle; Öneriler sekmesi sadece bunlarda izlenebilen film ve dizileri getirir. Boş bırakırsan filtre uygulanmaz.

IMDb puanlarını içe aktar

IMDb → hesabın → Your Ratings → sağ üstteki Export ile inen ratings.csv dosyasını seç. Tüm puanların İzlediklerim listesine taşınır; yüzlerce yapım tek seferde gelir.

TMDB kotasını zorlamamak için satırlar tek tek eşlenir; 500 satır yaklaşık 1 dakika sürer. Sekmeyi açık bırak.

Veri yedekleme

Tüm listelerin, puanların, notların ve dizi ilerlemen tek bir JSON dosyasında.

⚠️ Bu dosyada TMDB ve Google AI anahtarların açık metin olarak durur. Sadece kendi cihazların arasında taşı, kimseye gönderme.
